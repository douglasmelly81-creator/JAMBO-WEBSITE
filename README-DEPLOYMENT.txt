JamboDrive Autocare & Parts — GitHub Pages deployment

1. Create a GitHub repository (Public), for example: jambodrive-website.
2. Upload all files in this folder to the repository root (not the ZIP file itself).
3. Ensure index.html is at the root.
4. In repository Settings > Pages, select "Deploy from a branch", branch "main", folder "/(root)", then Save.
5. Wait for deployment and open the URL shown in Settings > Pages.

IMPORTANT:
- In script.js, replace WA_NUMBER="2547XXXXXXXX" with your real Kenyan WhatsApp number in international format, digits only (for example, 2547XXXXXXXX with the Xs replaced). Otherwise WhatsApp booking links will not work correctly.
- Review the phone number and business details on all pages before publishing publicly.
